# Demo-data source assets

`indiaLocations.json` is a compact derivative of the GeoNames India postal-code
dataset, downloaded from <https://download.geonames.org/export/zip/IN.zip>.
GeoNames publishes that dataset under CC BY 4.0. Place names, districts, states,
postal codes, and centre coordinates come from the 2026-09-17 dump. Coordinates
are centre estimates and are intentionally jittered within bounded radii by the
demo generator; they do not assert a real storefront at any address.

Pharmacy businesses, contacts, identifiers, and medicine brands are fictional
demo data. They must not be represented as verified real-world stock or pricing.
